# `[이번 차의 느낌]` — 설계 문서

> 기준일: 2026-08-29
> 상태: **설계 단계(구현 전)**
> 문서 역할: 타이머 뒤에 선택적으로 붙는 가장 얇은 시음 기록 기능의 상세 설계. 제품 기준은 `DESIGN.md`, 향미 도움은 `docs/sensory-vocabulary.md`, 장기 저장·백업 원칙은 `docs/data-portability.md`를 따른다.

---

## 1. 기능 정의

### 1.1 한 줄 정의

전체 우림이 끝난 뒤, **한 잔을 마신 직후의 감각을 자기만의 말로 가볍게 남기는 작은 시음 기록**.

차 정보 백과도, 긴 기록장도 아니다.

### 1.2 왜 만드는가

타이머만 사용해도 `차 한 잔의 시간`은 완전한 제품이다.

`[이번 차의 느낌]`은 기록 습관을 만들기 위한 기능이 아니라, 한 잔을 마신 뒤 조금 더 남겨보고 싶은 사람이 선택적으로 여는 작은 문이다.

사용자는 차를 우리기 위해 이미 차, 다구, 포수, 포별 시간을 선택하고 실행했다. 앱이 이미 알고 있는 것은 다시 묻지 않는다.

사용자가 추가로 남길 것은 앱이 알 수 없는 자기 감각뿐이다.

기록이 어느새 여러 잔 쌓이면 돌아볼 수 있지만, 기록 개수는 목표나 성취 조건이 아니다.

> **기록하지 않은 차도 온전한 차 한 잔이다.**

### 1.3 무엇이 아닌가

- 장기 통계, 별점, 점수화, 복잡한 맛 평가표가 아니다.
- "전문가식 향미 정답"을 맞히는 시험이 아니다.
- 매 포마다 입력해야 하는 실험 노트가 아니다.
- 앱 안에 모든 기록을 붙잡아 두는 데이터 락인 기록장이 아니다.
- 전문 기록 앱이나 개인 노트와 경쟁하지 않는다.

## 2. 목표와 비목표

### 2.1 목표

- 차 초보자가 시음노트를 "맞혀야 하는 정답"으로 느끼지 않게 한다.
- `단맛`, `꽃향`, `과일` 같은 넓은 기본 감각어에서 시작할 수 있게 한다.
- 사용자가 자기만의 비유를 자유롭게 남길 수 있게 한다.
- 타이머 사용 과정에서 이미 생긴 차·다구·포수·시간은 자동 요약한다.
- 기록을 텍스트/이미지/구조화 데이터로 가져갈 수 있는 기반을 만든다.
- 사용자가 표현에 막히면 `향과 맛의 단어장`으로 자연스럽게 연결한다.

### 2.2 비목표

- 기록 습관의 강요
- 매일 기록
- streak
- 10잔 목표 진행률
- 취향 점수
- AI 취향 판정
- 커뮤니티·SNS
- 전문 시음 관리 기능

## 3. 진입 흐름

핵심 제약:

> **기록 화면이 실제 차의 완료 행동보다 먼저 튀어나오면 안 된다.**

먼저 따르고 마신 뒤, 원하면 기록한다.

### 3.1 진입점

- 화면 우하단 푸터의 연필 라인 아이콘을 사용한다.
- 음소거 버튼과 같은 절제된 실루엣 톤을 유지한다.
- 최소 44px 터치 타깃과 명확한 aria-label을 유지한다.
- 우림 도중 기록 입력을 요구하지 않는다.

현재 구현은 `준비 중` 모달까지 완료되어 있다.

### 3.2 기록 단위

기록 단위는 **한 세션 전체 한 장**이다.

매 포마다 입력하지 않는다.

포 사이 시간은 차를 마시는 시간이다. 매 포마다 빈칸을 제시하면 차를 마시는 흐름이 기록 노동으로 바뀐다.

포별 변화가 기억에 남는다면 자유 메모에 `3포째가 가장 달았다`처럼 적을 수 있다. 포별 실제 시간은 앱이 자동으로 붙인다.

## 4. 입력 구조

입력은 세 층으로 나눈다.

```text
0단계 — 자동
차 · 다구 · 날짜 · 포수 · 포별 시간

1단계 — 한 번 탭
감각 태그

2단계 — 원한다면
자유 메모 · 찻잎 g · 물 ml · 실제 수온
```

깊게 기록하는 사람일수록 입력이 늘어나지만, 가볍게 기록하는 사람은 거의 아무것도 입력하지 않아도 된다.

### 4.1 상단 세션 자동 요약

자동으로 보여줄 후보:

- 선택 차
- 선택 다구
- 날짜
- 완료된 포 수
- 포별 실제 우림 시간

예:

```text
청향 우롱 · 개완
3泡 · 20 / 25 / 30초
```

사용자가 타이머를 쓰기 위해 이미 한 행동을 기록 폼에서 다시 묻지 않는다.

### 4.2 차 이름 보정

프리셋 `청향 우롱`보다 구체적인 이름을 남기고 싶은 사용자는 선택적으로 수정할 수 있다.

예:

```text
2026 화롄 밀향녹차
2024 아리산 청향 우롱
```

프리셋 ID와 사용자가 쓴 표시 이름은 분리해 보존하는 방향을 우선한다.

### 4.3 오늘 떠오른 단어

기본 태그는 넓고 쉬운 생활 언어를 우선한다.

현재 후보:

> 단맛 · 꽃향 · 과일 · 곡물 · 구운맛 · 견과 · 풀 · 나무 · 흙 · 연기 · 떫음 · 부드러움 · 맑음 · 묵직함

- 다중 선택
- 모든 태그는 선택 사항
- 전문적인 세부 향미를 처음부터 요구하지 않음
- 태그는 정답이 아니라 표현의 출발점

### 4.4 표현이 막힌다면

기본 태그 바로 아래에 작은 안내를 둔다.

> 전혀 감이 안 온다면 **향과 맛의 단어장 📗**을 구경해 보세요.

이 링크는 교육 과정이나 필수 단계가 아니다.

기본 태그만으로 충분한 사용자는 열지 않아도 된다.

단어장의 목적은 정답을 제시하는 것이 아니라, 사용자가 자기 기억 속의 맛과 향을 떠올릴 수 있게 단서를 제공하는 것이다.

상세 설계는 `docs/sensory-vocabulary.md`를 따른다.

### 4.5 조금 더 자세히 적는다면

자유 입력은 한두 줄을 기본으로 한다.

예:

- `흰 쌀밥을 오래 씹은 맛`
- `잘 후숙된 황도 껍질 같은 향`
- `표고버섯 불린 물 같은 향이 난다`
- `약수 마실 때처럼 돌 같은 느낌`
- `3포째가 제일 달았다`

전문 용어보다 사용자가 나중에 자기 기억을 다시 불러올 수 있는 표현을 우선한다.

### 4.6 더 남기고 싶다면

접힌 선택 영역으로 둔다.

- 찻잎 ___ g
- 물 ___ ml
- 실제 수온 ___ ℃

없어도 완전한 기록이다.

앱의 권장 온도는 실제 사용 온도가 아니다. 사용자가 실제 수온을 입력하지 않았다면 비워둔다.

## 5. 저장 상태

기록은 두 단계로 나누는 방향을 우선 검토한다.

### 5.1 세션 초안

- 사용자가 태그나 메모 입력을 시작하면 현재 세션 안에서 자동 보존한다.
- 시트를 닫거나 다음 포를 우리어도 작성 내용이 사라지지 않는다.
- 아직 장기 기록으로 확정된 것은 아니다.

### 5.2 기기에 남기기

- 사용자가 명시적으로 저장하면 IndexedDB의 Tea Session 기록으로 확정한다.
- 첫 장기 기록이 생기면 메뉴에 기록용 찻잔 아이콘과 숫자 배지를 보여주는 방향을 검토한다.

핵심 원칙:

> **타이머 사용 ≠ 기록 의사**

타이머를 돌렸다는 이유만으로 모든 차를 자동 기록하지 않는다.

반대로 사용자가 표현을 시작했는데 실수로 닫아 내용이 날아가는 경험도 피한다.

세부 저장·백업 원칙은 `docs/data-portability.md`를 따른다.

## 6. Export

### 6.1 빠른 공유

#### 텍스트

예:

```text
[차 한 잔의 시간]
• 차 / 다구: 청향 우롱 / 개완
• 날짜: 2026-08-29
• 우림: 1포 20초 | 2포 25초 | 3포 30초
• 느낌: 꽃향, 맑음
• 한마디: 잘 후숙된 황도 껍질 같은 향
```

개인 메모 앱, Obsidian, Notion, 다른 차 기록 앱 등에 쉽게 붙여넣을 수 있어야 한다.

#### 카드 이미지

- 앱과 같은 어두운 배경과 절제된 타이포그래피
- 해당 차의 탕색 포인트
- 로고·홍보 문구는 최소화
- 공유용 결과물이 앱 자체보다 튀지 않게 함

### 6.2 구조화 데이터

장기적으로 Tea Session Schema에 맞는 JSON export/import를 지원한다.

Plain Text/PNG는 빠른 공유, JSON/Markdown은 데이터 이동과 장기 보관이라는 역할을 구분한다.

## 7. 차 열 잔의 기록

`차 열 잔의 기록`은 목표가 아니다.

```text
🍵 1
🍵 2
...
🍵 9
🍵 10
```

사용자는 그냥 기록을 남긴다.

`7/10`, 진행률 바, `3잔 남았어요`, streak 같은 표현은 쓰지 않는다.

열 번째 기록이 생겼을 때 처음으로 조용히 회고 기능을 연다.

> **어느새 열 잔의 기록이 모였어요.**

### 7.1 회고에서 보여줄 것

- 자주 선택한 감각어
- 자주 사용한 다구
- 첫 기록과 최근 기록의 표현
- 새로 등장한 개인 단어
- 사용자가 남긴 문장 일부

### 7.2 해석하지 않는다

피할 것:

> 당신은 Floral Lover입니다.

지향할 것:

> 열 잔 중 여섯 잔에서 꽃향을 골랐어요.

앱은 해석자가 아니라 거울에 가깝게 남는다.

## 8. 개인 단어장과의 관계

시음 기록은 과거의 경험을 남긴다.

개인 단어장은 경험을 통해 사용자가 새로 획득한 감각 좌표를 남긴다.

예:

```text
처음 기록
#꽃향

경험이 쌓임
치자 · 인동초 · 돈나무꽃을 구별

개인 단어장
"비 온 뒤 돈나무꽃"
```

시음 기록보다 개인 단어장이 더 오래 중요한 사용자 자산이 될 수 있으므로 둘을 함께 백업할 수 있어야 한다.

## 9. 구현 단계

### MVP 1 — 가장 얇은 기록

- `준비 중` 모달을 실제 기록 시트로 교체
- 세션 자동 요약
- 기본 감각 태그
- 자유 문장
- 단어장 링크 자리
- 텍스트 export
- 세션 draft 보존

### MVP 2 — 장기 로컬 기록

- IndexedDB Tea Session
- `기기에 남기기`
- 기록용 찻잔 아이콘 + 숫자 배지
- 수정/삭제
- JSON/Markdown export 기반

### Later

- 카드 이미지 export
- `차 열 잔의 기록`
- 개인 감각 단어장 연동
- 공개 스키마

구현 순서는 `ROADMAP.md`의 전체 우선순위를 따른다.

## 10. 완료 기준

- 기록 기능을 전혀 쓰지 않아도 타이머 흐름이 이전과 동일하다.
- 차·다구·날짜·포수·포별 시간을 다시 입력하지 않아도 된다.
- 태그 하나만 골라도 기록할 수 있다.
- 자유 문장만 써도 된다.
- 아무 감각 입력 없이 자동 세션 정보만 보고 닫아도 된다.
- 표현이 막히면 단어장으로 갈 수 있지만 필수는 아니다.
- 작성 중 내용을 실수로 잃지 않는다.
- 장기 저장은 사용자의 의사 없이 모든 타이머 세션을 쌓지 않는다.
- 기록을 텍스트로 다른 도구에 가져갈 수 있다.
- 저장소를 쓸 수 없는 환경에서도 타이머는 정상 동작한다.
- reduced-motion, 44px 터치 타깃, aria 라벨 등 기존 접근성 기준을 유지한다.

## 11. 열린 질문

- 세션 draft를 메모리만으로 둘지 IndexedDB 임시 store로 둘지.
- `기기에 남기기` 버튼의 정확한 문구와 위치.
- 첫 저장 시 찻잔 아이콘을 즉시 노출할지, 다음 앱 진입부터 노출할지.
- 기본 태그 14종의 최종 구성.
- 카드 이미지 export를 MVP 2에 둘지 더 늦출지.
- 열 번째 기록에서 회고 기능을 알리는 표현과 모션 강도.

어떤 결정이든 **차를 마시는 것보다 기록을 앞세우지 않는다.**
