# `[이번 차의 느낌]` — 설계 문서

> 기준일: 2026-07-28
> 상태: **설계 단계(구현 전)**. `ROADMAP.md` 구현 우선순위 8.
> 문서 역할: `ROADMAP.md`의 기능 방향 서술을 분리해 상세화한 문서. 구현이 확정·완료되면 핵심 스펙은 `DESIGN.md`에 통합하고 이 문서는 히스토리로 남긴다.
> 표기 규칙: `ROADMAP.md`에서 이미 확정한 방향은 본문으로, 이 문서에서 새로 구체화한 내용은 **[제안]** 으로 표시한다.

## 1. 기능 정의

### 1.1 한 줄 정의
전체 우림이 끝난 뒤, **한 잔을 마신 직후의 감각을 자기만의 말로 한두 줄 남기는 작은 시음 카드**. 차 정보 백과도, 긴 기록장도 아니다.

### 1.2 왜 만드는가
앱 철학의 연장이다. 혼자 조용히 차를 마실 때 자기 감각을 다듬는 순간은 물론, 여럿이 모여 대화를 나누는 다회(茶會) 현장에서도 팽주와 팽객의 흐름을 방해하지 않고 자연스럽게 어우러지는 도구를 지향한다. 이 앱의 목표는 사용자를 차 전문가로 만드는 것이 아니라 "차 마시는 일이 조금 재밌다"는 감각을 만드는 것이고, 초보자에게 제안하는 작은 목표는 **열 잔을 마시고 내 말로 기록해 보는 것**이다. `[이번 차의 느낌]`은 그 첫 문이다 — 타이머만 쓰던 사용자가 원할 때만 열어 보는, 가장 얇은 기록의 입구.

### 1.3 무엇이 아닌가
- 장기 통계, 별점, 점수화, 복잡한 맛 평가표가 아니다.
- "전문가식 향미 정답"을 맞히는 시험이 아니다.
- **앱 안에 모든 기록을 붙잡아 두는 데이터 락인(Data Lock-in) 기록장이 아니다.** 기존 차 기록 앱(`차담`, `MyTeaPal` 등)이나 개인 노트(`Notion`, `Obsidian`, `기본 메모장`)와 경쟁하지 않으며, 유저의 데이터를 종속시키지 않고 원하는 곳 어디로든 자유롭게 내보내고 이동(No Lock-in)할 수 있는 오픈 도구를 지향한다.

## 2. 목표와 비목표

### 2.1 목표
- 차 초보자가 시음노트를 "맞혀야 하는 정답"으로 느끼지 않게 한다.
- `단맛`, `꽃향`, `구운맛` 같은 기본 감각 태그와 함께 자기만의 비유를 남길 수 있게 한다.
- 전체 우림이 끝났을 때 그날의 느낌을 한 장의 이미지나 텍스트로 내보낼 수 있게 한다.
- 개인적이고 이상한 비유를 허용한다. 기억에 남고 다른 사람에게 설명하기 쉬운 표현이면 좋은 기록이다.

### 2.2 비목표
- 기록 습관의 강요. 기록하지 않아도 타이머 경험은 온전해야 한다.
- 누적 기록의 기본 노출. `[차 열 잔의 기록]`은 설정에서 사용자가 직접 켠 뒤에만 보인다(§8).
- 커뮤니티·공유 기능. 카드 이미지는 사용자가 직접 공유하는 소재일 뿐, 앱이 공유 채널을 갖지 않는다.

## 3. 진입 흐름

핵심 제약: **기록 화면이 타이머의 완료 행동보다 먼저 튀어나오면 안 된다.** 먼저 따르고 마신 뒤, 원하면 기록한다.

- 완료 후 선택적으로 연다. 기본 타이머 동작(따르기, 표일배 배수, `다음 泡 우리기`)과 분리한다.
- **진입점은 화면 우하단 푸터의 노트 버튼이다(2026-07-12 확정).** 아이콘은 이모지가 아니라 음소거 버튼과 같은 실루엣 라인 SVG(연필, `currentColor` stroke)를 쓴다 — 이모지는 색이 고정되어 어두운 화면에서 튀므로 푸터의 보조 조작 톤에 맞지 않는다. 현재 그 자리의 응원 박수(👏)는 메인 화면에서 빼고 도움말에만 남긴다(`help.html`에 자체 박수 버튼·모달이 이미 있음). 박수는 제작자 대상 메타 행동이라 제작자 연락처가 있는 도움말이 제자리이고, 타이머 화면에는 차 우리기와 직접 관련된 조작만 남는다. 검증된 우하단 슬롯을 재사용하므로 주 액션 버튼과 시선 경쟁이 없다. aria-label은 `이번 차의 느낌 남기기`, 44px 터치 타깃 등 기존 푸터 버튼 패턴을 따른다.
- **노트 버튼을 누르는 순간이 저장 기준이다(2026-07-12 확정).** 누름은 "이 세션을 남기고 싶다"는 사용자의 선언이며, 앱이 세션 종료를 추측하지 않는다. 카드의 포별 시간 요약은 누른 시점의 세션 상태를 담는다.
  - 노출 시점: **완료된 포가 1개 이상인 done 상태에서만** 노트 버튼을 보인다. idle(0포)에는 기록할 것이 없고, pour/steep 중 숨김은 아래 제약 그대로다.
  - 같은 세션에서 다시 누르면 새 카드가 아니라 같은 세션 카드를 다시 열어 이어 쓰고, 포별 시간 요약은 최신 상태로 갱신한다. 세션 경계는 기존 초기화 지점(`처음부터`, 차·도구 전환)과 일치한다.
- **기록 단위는 세션 전체 한 장이다(2026-07-12 확정).** 매 포 완료마다가 아니라, 몇 포를 마셨든 그날 그 차의 한 세션을 카드 한 장이 담는다. 우림 도중에는 진입점을 노출하지 않는다.
  - 근거: 포 사이 시간은 차를 마시는 시간이라 포별 입력은 매 포마다 완료 행동을 밀어낸다. 초보자에게 포별 빈칸은 정답 압박이 된다. export 카드·"열 잔" 목표·저장 상한(§6)의 단위가 모두 세션이다. 포별 상세 기록은 전문 기록 앱의 영역이라 경계 원칙(§1.3)상 붙잡지 않는다.
  - 포별 변화의 재미는 자유 문장이 흡수한다(§4.1). "3포째가 제일 달았다" 같은 문장은 한 장 안에서 성립하고, 자동으로 들어가는 포별 시간 요약과 대조하는 재미도 남는다. 애호가 요구가 확인되면 "포별 한 단어 메모" 같은 얇은 확장을 그때 검토한다.
- **[제안]** 기록 화면은 별도 페이지 이동 대신 타이머 위에 얹히는 시트/모달로 열고, 닫으면 done 상태 그대로 돌아온다. 다음 포를 우리다가 돌아와도 흐름이 끊기지 않아야 한다.

## 4. 입력 및 UI 설계

입력은 얇고 직관적인 두 층이다. 모든 입력은 선택 사항(Optional)이며 순서 강제가 없다.

### 4.1 상단 세션 자동 요약 & 차 이름 수정 (✏️)
- 차 이름, 도구, 날짜, 마신 포 수, 포별 실제 우림 시간이 상단 카드로 자동 렌더링된다.
- 기본적으로 세션 프리셋(예: 청향 우롱)이 노출되지만, 요약 헤더 우측의 **연필 아이콘(✏️)**을 클릭하여 `2024 대만 아리산 청향 우롱`처럼 차/도구 이름을 자유롭게 인라인 수정할 수 있다.
- **차종 상징 이모지 2계열 분류**: 시각적 조잡함을 피하고 절제된 미학을 위해 차종 이모지는 2계열로만 심플하게 나눈다: `🍃` 청차계 (녹차, 말차, 백차, 황차, 청향 우롱, 포종, 봉황단총, 보이 생차) vs `🍂` 농차/숙차계 (농향 우롱, 무이암차[대홍포·육계·수선], 동방미인, 호지차, 홍차, 흑차/보이 숙차).

### 4.2 오늘 떠오른 단어 (감각 태그)
- 타이틀: **`오늘 떠오른 단어`**
- 앱이 제안하는 기본 태그 14종:
  > 단맛 · 꽃향 · 과일 · 곡물 · 구운맛 · 견과 · 풀 · 나무 · 흙 · 연기 · 떫음 · 부드러움 · 맑음 · 묵직함
- MVP에서 태그는 44px 터치 타깃 다중 선택 칩(Pill buttons)으로 구현한다. 탭하면 금색 테두리와 글로우가 켜지는 직관적 토글 방식.

### 4.3 조금 더 자세히 적는다면 (자유 입력창)
- 타이틀: **`조금 더 자세히 적는다면`**
- 입력창 하단 캡션 가이드: *"나만의 비유를 넣거나, 차 마실 때의 분위기나 장소를 간단히 적어보세요."*
- 사용자가 직접 한두 줄을 자유롭게 쓴다. (예: `흰 쌀밥을 오래 씹은 맛`, `비 오는 날 창가에서 마심`, `3포째가 제일 달았다`)

### 4.4 하단 액션 버튼 (3종)
1. **`💾 임시 저장`**: 포(泡) 사이사이에 기록을 남기고 닫아도, 세션이 유지되는 동안 내용이 지워지지 않고 보존된다.
2. **`📋 텍스트 복사`**: 클립보드 복사 (`차담`, `Notion`, `Obsidian`, `기본 메모장` 등 붙여넣기용).
3. **`🖼️ 카드 이미지 저장`**: Canvas로 PNG 시음 카드를 생성하여 저장/공유.

## 5. export 카드

### 5.1 구성
- 자동 정보(§4.3) + 사용자가 고른 태그 + 직접 쓴 문장을 함께 보여 준다.
- **[제안]** 시각 톤은 앱과 같은 어두운 배경·Gowun Batang·해당 차의 탕색 포인트를 쓴다. 카드만 봐도 "차 한 잔의 시간에서 나온 기록"임이 느껴지되, 로고·홍보 문구로 시선을 뺏지 않는다.

### 5.2 두 가지 출력
| 형식 | 용도 | 방식 **[제안]** |
|---|---|---|
| 카드 이미지 | 공유용 | 오프스크린 canvas 렌더 → PNG. Web Share API 가능하면 공유 시트, 아니면 다운로드 |
| 텍스트 | 개인 메모 앱 붙여넣기용 | 클립보드 복사. `차담`, `Notion`, `Obsidian`, `기본 메모장` 등 사용자가 이미 쓰는 어떤 앱에 붙여넣어도 깔끔한 오픈 텍스트(Plain Text) 형태 |

- **[제안]** 빌드 없는 단일 `index.html` 원칙을 지키기 위해 이미지 생성 라이브러리를 들이지 않고 canvas 직접 렌더로 한다. 카드 레이아웃이 단순하므로 감당 가능한 범위다.
- **[제안] 텍스트 Export 예시 포맷**:
  ```text
  [차 한 잔의 시간]
  • 차종 / 도구: 청향 우롱 / 개완
  • 날짜: 2026-07-28
  • 우림 기록: 1포 20초 | 2포 25초 | 3포 30초
  • 감각 태그: 단맛, 꽃향
  • 한 줄 느낌: 흰 쌀밥을 오래 씹은 듯 고소하고 달다.
  ```

## 6. 데이터 저장 **[제안]**

이 절 전체가 제안이다. 경계 원칙("앱 안에서 모든 기록을 붙잡으려 하지 않는다")과 `[차 열 잔의 기록]`(최근 열 번을 돌아보기)을 동시에 만족하는 최소 저장을 설계한다.

- 별도 키 `teaTimer.cups.v1`에 저장한다. 기존 `teaTimer.preferences.v1`과 섞지 않는다 — 선호값과 기록은 수명과 삭제 단위가 다르다.
- 저장 형태:

```js
{
  version: 1,
  cups: [
    {
      at: "2026-07-12T21:30:00+09:00",   // 기록 시각
      teaId: "oolong",
      vesselId: "gaiwan",
      infusions: [20, 25, 30],            // 포별 실제 우림 초
      tags: ["단맛", "꽃향"],
      note: "흰 쌀밥을 오래 씹은 맛"
    }
  ]
}
```

- `cups`는 **최근 10장까지만** 보관하고 초과분은 오래된 것부터 버린다. 이 상한이 "기록장이 되지 않는다"는 경계의 구현이며, 10이라는 숫자는 `[차 열 잔의 기록]`의 재료가 된다. 더 오래 남기고 싶은 카드는 export가 담당한다.
- 카드를 저장하지 않고 export만 하고 닫는 것도 허용한다(저장 버튼과 export 버튼을 분리).
- 오류 처리는 `teaTimer.preferences.v1`과 같은 원칙: 저장 실패·파싱 실패는 조용히 무시하고, 기록 기능이 죽어도 타이머는 정상 동작한다.
- 도움말의 저장값 삭제 동작에서 기록도 함께 지울지, 별도 항목으로 둘지는 열린 질문(§10)이다.

## 7. 구현 단계 **[제안]**

ROADMAP 우선순위 8 `[이번 차의 느낌]` 기록 MVP를 두 단계로 쪼갠다.

| 단계 | 범위 | 비고 |
|---|---|---|
| 선행 정리 | 메인 화면 푸터의 응원 박수(👏) 제거(도움말에만 유지), 그 자리에 연필 라인 아이콘 노트 버튼 + `준비 중` 안내 모달 | **완료(2026-07-12).** placeholder 단계에서는 노트 버튼이 항상 보이고, done 한정 노출 규칙(§3)은 MVP 1에서 적용한다 |
| MVP 1 | 노트 버튼의 `준비 중` 모달을 실제 기록 시트로 교체 + done 한정 노출 + 태그 14종 + 자유 문장 + 텍스트 export(클립보드) | 저장 없이도 성립. 가장 얇은 문 |
| MVP 2 | 카드 이미지 export(canvas) + `teaTimer.cups.v1` 최근 10장 저장 | 이미지 톤 잡기에 시간이 들므로 분리 |

핵심 타이머 흐름(백그라운드 보정, 즉시 멈춤 등 우선순위 1–7)이 안정된 뒤 시작한다는 전제는 ROADMAP 그대로다.

## 8. 선택형 확장: `[차 열 잔의 기록]`

- `[이번 차의 느낌]` 사용 반응이 충분히 좋을 때만 검토한다.
- 초보자의 첫 목표인 "열 잔을 마시고 내 말로 기록해 보기"를 돕는 페이지다.
- 최근 열 번의 차 카드, 자주 고른 감각 태그, 반복해서 등장한 개인 비유를 가볍게 돌아보게 한다.
- 전체 차 생활을 관리하는 기록장이나 통계 대시보드가 아니다.
- 설정에서 사용자가 직접 켜기 전에는 앱 내비게이션과 기본 화면에 노출하지 않는다.

## 9. 장기 비전: `[차 백 잔의 창고]`

- 기본 목표가 아니다.

- 이 단계에서도 핵심은 점수화나 과시가 아니라, 오래 마신 시간이 자기만의 언어로 쌓였다는 즐거움이다.

## 11. 완료 기준 (MVP)

- 노트 버튼(연필 라인 아이콘)은 완료된 포가 1개 이상인 done 상태에서만 보이고, idle·pour·steep에서는 보이지 않는다.
- 메인 화면에 응원 박수(👏)가 없고, 도움말의 박수 버튼·모달은 그대로 동작한다.
- 기록을 열지 않고 `다음 泡 우리기`·표일배 배수를 진행하는 흐름이 이전과 완전히 동일하다.
- **모든 다구의 우림 완료 후 따라내기 (出湯) 단계 지원**:
  - 우림 완료 시 메인 버튼이 `차 따라내기` (표일배는 물리적 버튼 구조를 반영해 `버튼 눌러 내리기`)로 변경된다.
  - **개완 (`gaiwan`)**: 따라내기 시 1.4초 동안 찻물이 그릇 밖으로 빠져나가고, 촉촉하게 펼쳐진 찻잎만 그릇에 남아 시각화된다.
  - **불투명 다구 (`teapot`, `eastern-pot`, `mug`)**: 따라내기 시 피어오르던 김(Steam)과 글로우가 스르륵 사라진다.
  - **표일배 (`piaoyibei`)**: 상부 챔버에서 하부 포트로 찻물이 내려오는 애니메이션이 유지된다.
  - 따라내기가 마치면 메인 버튼이 `다음 泡 우리기`로 전환된다.
- **세션 락(Session Lock) 차/다구 변경 보호**:
  - 우림 기록이 없는 상태(`infusionHistory.length === 0`)에서는 차와 다구를 자유롭게 바꿀 수 있다.
  - 1포 이상 우린 기록이 발생한 상태(`infusionHistory.length > 0`)에서는 차/다구 변경이 잠기며, 변경 시도 시 *"아직 우리고 있는 중인 차가 있습니다. 차를 바꾸려면 [우림 끝]을 눌러주세요 🍵"* 안내 토스트가 노출된다. 상단 `[우림 끝]`을 명시적으로 눌러 마감한 경우에만 새 차/다구를 고를 수 있다.
- 같은 세션에서 노트 버튼을 다시 누르면 이전 입력이 남아 있는 같은 카드가 열리고, 포별 시간 요약이 최신 상태로 갱신된다.
- 태그만, 문장만, 혹은 아무것도 입력하지 않아도 카드가 성립한다(자동 정보만으로도 export 가능).
- 텍스트 export를 개인 메모 앱에 붙여넣었을 때 차·도구·날짜·포별 시간·태그·문장이 읽기 좋게 들어간다.
- 저장소를 쓸 수 없는 환경에서도 기록 시트와 export가 동작하거나, 조용히 비활성화되고 타이머는 영향받지 않는다.
- reduced-motion, 44px 터치 타깃, `aria` 라벨 등 기존 접근성 기준(`DESIGN.md` §8)을 기록 시트에도 적용한다.

## 12. `help.html` (사용법) & `settings.html` (개인 설정) 2원화 명세

1. **`help.html` (사용법 전용 페이지)**:
   - 좌상단: `← 처음으로` (index.html 메인으로 이동)
   - 우상단: `⚙️` (settings.html 설정 페이지로 이동)
   - 내용: 5단계 가이드 (`차/다구 고르기`, `시간 맞추기 & 우리기`, `다음 泡 우리기 & 표일배 배수`, `차 느낌 남기기`, `우림 끝내기`), 자유롭게 쓰세요(오프라인/오픈소스), 제작자 이야기 & 👏 응원 박수
2. **`settings.html` (개인 설정 전용 페이지)**:
   - 좌상단: `← 처음으로` (index.html 메인으로 이동)
   - 우상단: `ⓘ` (help.html 사용법 페이지로 이동)
   - 내용:
     - 7종 차별 권장/보정 시간 관리 (- / + 조작 및 차별 기본값 복원)
     - 오늘 떠오른 단어 태그 관리 (새 단어 추가 / ✕ 삭제 / 기본 14종 복원)
     - 기억한 설정 지우기 (전체 데이터 초기화)
3. **네비게이션 규칙**:
   - 메인 화면(`index.html`) 상단 우측 메뉴 `사용법` ➔ `help.html`로 연결.
   - 서브 페이지들(`help.html`, `settings.html`)의 메인 복귀 버튼 텍스트는 **`← 처음으로`**로 통일.

## 13. 도출된 디자인 원칙 & Lessons Learned

1. **선(Line)을 지우고, 면(Fill)과 여백으로 말하라 (Border-Free Materialism)**
   - 요소를 구분하기 위해 테두리 선(Border)을 남발하면 시각적 노이즈와 피로도가 급증한다.
   - 선을 지우고 은은한 미세 불투명도 면(Tint Fill: `background: rgba(205,191,99,0.14)`, `border: none`)과 여백으로 컴포넌트를 정돈할 때 동양 다도의 고즈넉함과 젠(Zen) 미학이 확립된다.

2. **유저에게 정답을 요구하지 않는 '안도감과 허용'의 언어 (Language of Permission)**
   - `[오늘 떠오른 단어]`, `[조금 더 자세히 적는다면]` 및 안내 가이드(*"차 마실 때의 분위기나 장소를 간단히 적어보세요"*)처럼 어떤 형태의 경험이든 훌륭한 기록이 된다는 안도감과 허용의 언어를 사용할 때 유저의 기록 장벽이 낮아진다.

3. **데이터 락인(Data Lock-in) 배제와 상생의 개방성 (Open Data Interoperability)**
   - 회원가입/중앙 DB를 거부하고, 1초 만에 `차담`, `Notion`, `메모장` 등 유저가 이미 쓰는 어떤 노트 앱으로든 털고 나갈 수 있는 오픈 텍스트(Plain Text) 및 이미지 Export를 제공할 때 무욕(無欲)의 신뢰와 압도적인 유저 자유도가 확보된다.

4. **물리적 습관과 맥락을 따르는 정보 밀도 (Contextual Density & Safety)**
   - 알약형 칩(`999px`) 대신 모서리 라운드니스를 `4px`로 최소화하고 패딩을 단어 경계에 바짝 붙여 한눈에 들어오는 정보 밀도를 확보한다.
   - 상단 세션 마감 버튼은 다회 언어를 반영해 `우림 끝`으로 명시하며, 오타 방지를 위해 엄지 영역이 아닌 상단 안전 구역에 유지한다.

5. **가변 요소의 세심한 시각적 균형과 대칭성 (Balanced Visual Harmony)**
   - 카드 이미지 생성 시 선택된 태그 개수에 따라 줄 수를 계산하고 줄별로 태그를 균등 분배(Balanced Distribution)하여 어떤 태그 조합에서도 visual 대칭성과 정갈함을 유지한다.
