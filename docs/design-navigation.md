# 화면 배치와 메뉴 표현 — 확장 설계

> 결정일: 2026-08-31
> 상태: **배치·진입 원칙 결정, 런타임 미반영**. 후속 기능의 화면 내용과 데이터 모델은 각 Phase에서 설계·검증한다.
> 범위: TW의 언어 진입점과 Phase B–F·Later의 기록함·단어장·회고·레시피·데이터 이동. 기능 추가나 Phase 앞당김을 뜻하지 않는다.
> 관련 문서: [DESIGN](DESIGN.md), [ROADMAP](ROADMAP.md), [다국어](design-localization.md), [차 느낌](design-tea-feeling.md), [데이터 보존](data-portability.md), [단어장](sensory-vocabulary.md).

## 1. 메인은 계속 차를 우리는 화면이다

메인의 고정 영역은 **세션/앱 조작 → 차·다구·시간 → 출탕 → 소리·이번 차 느낌**으로 유지한다. 기록함·단어장·레시피를 위해 하단 탭이나 새 상시 아이콘 줄을 추가하지 않는다. 기능이 늘어도 기존 주요 조작의 위치가 이동하지 않게 한다.

```text
우림 끝                    [언어 아이콘 한국어 ▾] [☰ 메뉴]
                   차 한 잔의 시간
                      Time for Tea
               ‹ 차 선택 / 찻잎 미리보기 ›
                   ‹ 다구 / 남은 시간 ›
                 권장 우림 · 완료 포 기록
                        시간 조정
                 [우리기 시작 / 지금 따르기]
소리 아이콘 소리 끄기                         펜 아이콘 차 느낌
```

- 좌상단 `우림 끝`은 세션 경계를 뜻하는 텍스트 버튼으로 유지한다. 원형 화살표나 휴지통으로 대체하지 않는다.
- 우상단은 언어 선택과 `메뉴` 두 개다. 이전 제안의 `사용법 + 언어`에서 **사용법 자리를 메뉴로 대체**한다. 사용법은 메뉴 안으로 이동하고 설정도 메뉴에서 바로 접근한다.
- 언어는 `언어 아이콘 + 한국어/繁體 + ▾`, 메뉴는 `햄버거 아이콘 + 메뉴`다. 언어를 전역 메뉴 속에만 숨기지 않는다. 이름을 못 읽어도 언어 아이콘과 원어 선택지로 찾을 수 있게 한다.
- 기존 푸터의 소리와 차 느낌은 아이콘+문구를 유지한다. 여백이 있는 상태에서 굳이 이름을 없애지 않는다. 소리 문구는 기존 동작 라벨 `소리 켜기/끄기`와 아이콘 상태를 일치시킨다.
- 현재 포의 출탕과 다음 포는 항상 메인 주 버튼이다. 기록·공유·레시피 저장을 이 버튼에 섞지 않는다.

## 2. 전역 메뉴와 맥락 진입

메뉴 안에서는 구현된 목적지만 같은 순서로 표시한다. 관련 항목이 있을 때만 그룹 간 여백을 둔다. 미구현 기능의 회색 행·잠금 아이콘·준비 중 배너를 예고용으로 보여주지 않는다.

| 기능 | 주 진입점 | 보조 진입점 / 해당 화면의 역할 |
|---|---|---|
| 이번 차 느낌 | 메인 푸터 `펜 + 차 느낌` | 현재 세션 한 장 작성. 과거 기록 목록을 이 버튼에 합치지 않음 |
| 기록함 | 메뉴 `노트 아이콘 + 기록함` | `기기에 남기기` 성공 후 `기록함 보기`, 개별 기록 상세·공유·삭제 |
| 감각 단어장 | 느낌 시트 태그 아래 `책 아이콘 + 단어 찾아보기` | 메뉴 `책 아이콘 + 단어장`은 독립 탐색. 안에서 감각 단어/내 단어 구분 |
| 레시피 | 메뉴 `순서 목록 아이콘 + 레시피` | 완료 기록/현재 완료 세션의 `이 우림 기억하기`로 작성, 레시피 상세에서 `이대로 준비하기` |
| 열 잔 회고 | 기록함 내부의 `지난 차 돌아보기` | 별도 메인 아이콘·탭 없음. 열 잔이 쌓였을 때 조용한 안내, 홈 배지/목표/자동 팝업 없음 |
| 사용법 | 메뉴 `도움말 아이콘 + 사용법` | 사용법·앱 설명·제작자 연락·응원은 이 안에 유지 |
| 개인 설정 | 메뉴 `설정 아이콘 + 설정` | 언어, 차별 시간 보정, 태그 목록 편집, 설정 초기화 |
| 전체 백업·복원 | 설정의 `데이터 보관과 이동` | `백업 파일 내보내기` / `백업 파일 가져오기`. 개별 카드 공유와 구분 |
| 개별 기록 내보내기 | 기록 상세의 `공유·내보내기` | 텍스트·이미지·후속 JSON/Markdown 중 실제 지원하는 형식만 표시 |
| g·ml·실제 수온 | 느낌 시트의 접힌 `우림 정보 더 적기` | 선택 입력. 권장 수온을 실제 수온으로 자동 입력하지 않음 |
| 사용자 차 등록 | 향후 차 선택 상세의 `내 차 추가` | 메인에 새 + 버튼을 추가하거나 기본 캐러셀 조작과 혼합하지 않음 |

메뉴의 순서는 **기록함 → 단어장 → 레시피 / 사용법 → 설정**이다. 언어는 메뉴 밖에 직접 노출하고 설정에서도 같은 선택값을 관리한다. 차 캐러셀 스와이프·개완 뚜껑·탕색·폰트·오디오 안정화에는 새 메뉴가 필요하지 않다.

레시피를 기록함 안에만 넣는 안도 검토했으나, 과거 기록을 읽는 일과 우림 전에 저장한 방식을 준비하는 일은 진입 목적이 다르므로 메뉴에서 독립 진입을 제공한다. 대신 레시피 작성은 실제 우림 기록의 맥락에서 시작한다. 레시피 선택만으로 타이머를 시작하거나 기존 초안·선호 보정을 덮어쓰지 않는다.

## 3. 기능 도입 단계와 사용 이력은 구분한다

| 단계 | 메인 고정 조작 | 메뉴 / 맥락 진입 |
|---|---|---|
| TW-01–04 | 기존 화면 유지, 접근성과 상태 경계 안정화 | 기존 도움말/설정 동선에 이탈 보호 적용 |
| TW-05·06 | 우상단 언어 + 메뉴 적용, 중앙/푸터 유지 | 메뉴에는 사용법·설정만. 언어 전환은 같은 문서에서 수행 |
| Phase B: 장기 기록 구현 후 | 상시 기록 아이콘이나 숫자 배지 추가 없음 | 기록함 메뉴, 느낌 시트의 명시적 `기기에 남기기`, 성공 뒤 `기록함 보기` |
| Phase C: 데이터 이동 구현 후 | 변화 없음 | 설정에 백업·복원, 기록 상세에 구조화 내보내기 |
| Phase E·F 구현 후 | 변화 없음 | 단어장 메뉴·시트 맥락 진입, 기록함 안 선택적 회고 |
| Later: 레시피 구현 후 | 변화 없음 | 레시피 메뉴와 완료 기록의 작성 액션 |

- **기록함 메뉴는 기능이 구현되면 0개여도 접근 가능**하게 한다. 빈 기록함은 `아직 기기에 남긴 기록이 없습니다`와 타이머로 돌아가는 길만 제공하고, 목표·기록 강요·예시 사용자 데이터는 넣지 않는다.
- 앞서 검토한 `첫 저장 후에만 기록 메뉴를 노출`은 채택하지 않는다. 메뉴 안의 목적지 위치를 사용량에 따라 바꾸지 않고, 첫 저장 성공 때는 맥락 링크로 자연스럽게 발견하게 한다. 홈에 상시 기록 버튼을 추가하는 것과는 다르다.
- 단어장과 레시피도 해당 기능의 구현 여부로 노출한다. 기록 개수로 잠그지 않는다. 마지막 기록이나 레시피를 지웠다고 메뉴 자체를 없애지 않는다. 가져온 기록도 같은 위치에서 접근한다.
- 열 잔은 기록함 내부의 회고 제안 시점이다. `7/10`, 홈 개수 배지, 목표 달성 연출, 초과 기록 자동 삭제를 만들지 않는다. 회고 내용과 표본 선정은 Phase F에서 검증한다.

## 4. 아이콘과 문구를 고르는 기준

**위치를 기억하게 돕는 목적지에는 아이콘+이름, 결과를 정확히 말해야 하는 행동에는 문구, 주변 맥락만으로 의미가 분명한 작은 조작에는 아이콘만** 사용한다. 아이콘이 공간을 차지하는 만큼 실제로 찾거나 상태를 읽는 데 도움이 있어야 한다.

| 표현 | 적용 항목 | 판단 이유 / 조건 |
|---|---|---|
| 아이콘 + 메뉴명 | 언어 선택, 메뉴, 차 느낌 | 아이콘만으로 뜻이 확정되지 않고 첫 사용자가 발견해야 함 |
| 아이콘 + 메뉴명 | 기록함, 단어장, 레시피, 사용법, 설정 | 서로 다른 목적지를 훑어 찾기 쉽게 하고 뜻은 이름이 전달. 메뉴 행의 아이콘 열을 일관되게 유지 |
| 아이콘 + 문구 | 소리 켜기/끄기 | 소리 유무는 중요한 상태. 스피커/빗금과 동작 문구로 중복 전달 |
| 아이콘 + 문구 | 타이머로 돌아가기, 단어 찾아보기, 텍스트 복사, 이미지 저장, 공유·내보내기 | 돌아갈 곳이나 결과 형식이 분명해야 함. 그림만으로 복사/공유/다운로드를 추측하게 하지 않음 |
| 문구 중심 | 우리기 시작, 지금 따르기/내리기, 다음 포 우리기, 우림 끝 | 상태별로 결과가 달라짐. 재생/정지/리셋 그림보다 실제 행동을 말하는 문구가 정확 |
| 문구 중심 | 기기에 남기기, 내용 유지하고 닫기, 이 우림 기억하기, 이대로 준비하기 | 임시 유지·장기 저장·레시피 작성·실행 준비의 의미를 구분. 플로피 디스크 그림으로 통일하지 않음 |
| 문구 중심 | 취소, 삭제, 초기화, 백업 가져오기, 확인 | 파괴적이거나 결과가 중요한 동작. 휴지통·체크만으로 대체하지 않음 |
| 문구 중심 | 한국어 / 繁體中文（台灣）, 태그, 감각 단어/내 단어, 설정 행 | 내용 자체가 구분 기준. 선택 체크·접힘 화살표는 보조 상태 표시 |
| 아이콘만 | 차/다구 이전·다음, 시간 −/+, 닫기 X | 조작 대상이 바로 옆에 있고 관례가 명확. 접근성 이름은 대상·동작을 구체적으로 제공 |
| 아이콘만, 맥락 한정 | 차 이름 옆 편집 펜, 개별 기록 행의 더보기 | 대상이 같은 행에 명확하고 위험한 실행을 직접 하지 않을 때만. 더보기 안의 삭제는 문구+확인 |

- 언어를 국기로 표시하지 않는다. 언어 아이콘과 원어 이름을 쓴다. 햄버거는 전역 목적지, 세 점은 특정 기록의 추가 동작으로 역할을 구분한다.
- 실제 앱의 제어 아이콘은 기존 선형 SVG 계열로 통일한다. 이모지는 차의 표현이나 사용자 원문에 남길 수 있지만, 플랫폼마다 모습이 다른 이모지를 조작 아이콘 체계로 늘리지 않는다.
- 아이콘만 있는 모든 버튼도 실제 button과 접근성 이름을 갖는다. 예: `이전 차`, `다음 다구`, `우림 시간 1초 줄이기`, `느낌 시트 닫기`, `아리산 기록의 추가 동작`.
- 시각·유효 터치 크기를 구분한다. 아이콘은 약 18–20px로 작아도 조작 영역은 44×44px 이상이며 이웃과 겹치지 않는다. 툴팁은 보조이며 모바일에서 이름을 대체하지 않는다.
- 언어 버튼/메뉴는 펼침 상태, 소리는 눌림 상태, 언어·태그는 선택 상태를 보조기술에도 전달한다. 색 하나로만 구분하지 않는다.

## 5. 열기·닫기와 진행 중 우림

### TW 범위

- 언어와 전역 메뉴는 같은 문서의 작은 popover로 열며 둘을 동시에 겹쳐 열지 않는다. 메뉴를 여는 것 자체는 타이머·초안을 바꾸지 않는다. 언어 선택·Escape로 닫으면 트리거로 포커스를 돌린다. 목적지 선택은 해당 화면으로 포커스를 넘기고, 바깥의 다른 조작을 눌러 닫았으면 그 조작의 포커스를 빼앗지 않는다.
- **메인에서 사용자가 직접 고른 언어는 우림 중에도 문구만 갱신**한다. 선택한 차·다구·시간·완료 포·태그·메모를 그대로 유지하고 완료음을 재실행하지 않는다. IME 조합 중이거나 공유용 스냅샷 생성 중에는 해당 작업을 마친 뒤 적용한다.
- 언어 선택은 다른 HTML로 이동하지 않는다. 따라서 이전의 안전 idle까지 페이지 이동을 미루는 규칙과 구분한다. 다른 탭에서 들어온 언어 변경은 기존대로 안전한 상태까지 유예해 작성 도중 예고 없이 문구를 바꾸지 않는다.
- 메뉴의 사용법·설정은 현재 별도 문서이므로 [이탈 보호](design-localization.md#navigation-policy)를 계속 적용한다. 이 정책 때문에 언어까지 잠그지 않는다. 메뉴를 자동으로 목적지로 이동시키거나 초안을 대신 삭제하지 않는다.
- 메뉴나 언어 popover를 열어도 타이머 완료음은 계속 동작한다. 어느 popover든 중요한 시간/출탕을 가린 상태에서 완료되면 그 안에서도 완료 상태와 `타이머로 돌아가기`를 제공한다. 이 동작은 popover를 닫고 메인 출탕 버튼에 포커스를 두며 출탕 자체를 실행하지 않는다. 자동 포커스 이동이나 기록 시트 자동 열기는 하지 않는다.

### 장기 기록·단어장 이후

- 느낌 시트에서 여는 단어장은 **같은 문서 안의 보조 뷰**다. 새로운 페이지로 떠나지 않는다. 태그·메모·입력 위치를 유지하고 `느낌으로 돌아가기`로 복귀한다. 시트 안에서 다시 시트가 무한히 쌓이지 않도록 최대 한 단계의 보조 뷰로 제한한다.
- 메뉴에서 여는 단어장과 시트에서 여는 단어장은 같은 내용을 사용하지만 돌아갈 곳이 다르다. 뒤로 가기는 항상 진입 맥락으로 복귀하고 사용자 입력을 초기화하지 않는다.
- 단어를 읽거나 상세를 여는 것만으로 태그·메모를 바꾸지 않는다. 느낌에서 들어왔을 때만 `이 단어 고르기` 같은 명시적 동작으로 선택 태그에 반영하고 느낌으로 돌아온다. 이미 선택된 단어를 중복 추가하거나 메모에 설명문을 자동 삽입하지 않는다. 단어장의 ID·개인 단어와 기존 태그의 연결은 Phase E 데이터 설계에서 확정한다.
- 기록함·레시피 같은 후속 전체 화면은 타이머 상태를 보존하는 같은 문서 내 뷰를 우선한다. 활성 세션이 있을 때는 짧은 진행 상태와 `타이머로` 복귀 액션을 화면에 유지한다. 상태 공유·접근성·완료 알림 검증 전에는 활성 세션에서 별도 문서로 보내지 않는다.
- 레시피 불러오기·다른 차 준비처럼 현재 세션을 대체하는 행동은 단순 탐색과 구분한다. 활성 세션/초안이 있으면 보호 절차를 거치고 자동 폐기하지 않는다. 선택한 레시피를 확인해 `이대로 준비하기`를 눌러도 실제 우림 시작은 메인 주 버튼에서 한다.

## 6. 검토한 대안과 보류 이유

| 대안 | 판단 |
|---|---|
| 하단에 타이머·기록·단어장·레시피 탭 4개 | 보류. 375×660의 출탕 영역을 줄이고 기록하지 않는 사용자에게 상시 목적지를 강요함 |
| 기록함 하나에 단어장·레시피·회고를 모두 숨김 | 회고만 채택. 단어 탐색·우림 준비는 기록 읽기와 목적이 다르고 저장 기록이 없어도 접근할 수 있어야 함 |
| 메인에 언어·설정·기록·단어장 아이콘만 나열 | 채택하지 않음. 슬롯이 늘어나고 그림의 뜻을 외워야 함 |
| 모든 버튼에 아이콘 추가 | 채택하지 않음. `우림 끝`과 `기기에 남기기`처럼 결과 문구가 핵심인 행동은 문구가 우선 |
| 장기 기록 첫 저장 전에는 메뉴 위치 숨김 | 채택하지 않음. 홈을 늘리지 않고 메뉴 안에서 안정된 위치를 제공. 첫 저장 후 안내는 맥락 링크로 처리 |

탭은 추후 **같은 세션에서 타이머↔기록 왕복이 반복되고**, 메뉴가 실제 탐색 실패·불필요한 반복 조작을 만들며, 작은 화면에서 시간·출탕·44px 조작 영역을 지킨다는 근거가 있을 때만 재검토한다. 기능 수가 늘었다는 사실만으로 탭을 도입하지 않는다.

## 7. 검증과 구현 경계

- 375×660 및 더 좁은 320px에서 한국어·번체 상단 조작이 줄바꿈/겹침 없이 표시되는지 확인한다. 좁아져도 언어·메뉴 이름을 아이콘만으로 몰래 바꾸지 않는다. 가용 공간에 맞춰 제목/장식 간격을 먼저 줄인다.
- 타이머만 사용한 첫 방문자, 빈 기록함, 첫 명시적 저장, 기존 기록 가져오기, 마지막 기록 삭제, 열 잔 회고, 레시피 준비를 각각 확인한다. 자동 기록·사용량 잠금·홈 개수 배지가 없어야 한다.
- 키보드·스크린리더로 메뉴/언어의 열기·닫기·포커스 복귀, 느낌→단어장→느낌 복귀, 모달 밖 포커스 차단, 태그 선택과 소리 상태를 확인한다.
- 활성 우림 중 언어 변경·메뉴 열기·정상/조기 완료, 메모 IME 입력, export 중 전환, 레시피로 교체하려는 동작에서 상태 보존을 확인한다.
- TW-05에 포함되는 구현은 언어 popover·전역 메뉴와 기존 사용법/설정 연결뿐이다. 기록함·장기 저장·백업·단어장·회고·레시피·선택 입력은 각각의 Phase에 남긴다.
- 이번 인터랙티브 미리보기는 배치와 진입을 검토하는 예시다. 실제 저장·타이머·번역 전체·접근성·PWA 구현 완료의 근거로 사용하지 않는다. 구체적 검증 기록은 구현 시 CHANGELOG에 구분해 남긴다.
