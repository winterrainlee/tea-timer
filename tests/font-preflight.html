TW-05 글꼴·PNG 사전 점검

저장소 루트에서 python3 -m http.server 8134 --bind 127.0.0.1을 실행한 뒤 이 페이지를 엽니다. http://127.0.0.1:8134 전용 harness이며, 이 origin의 teaTimer.preferences.v1 원본 값만 실행 동안 임시 교체했다가 복원합니다.

실제 index.html을 fetch해 <base href="../">를 둔 srcdoc iframe으로 실행합니다. 정상 모드와 외부 글꼴 차단 모드 모두 실제 카드 PNG 생성 경로를 사용합니다. Web Share는 PNG 파일만 수집하는 대역이며 전송하지 않습니다. 화면·원본 PNG 결과는 수동 확인용이며 글꼴 품질이나 실기기 결과를 판정하지 않습니다.
